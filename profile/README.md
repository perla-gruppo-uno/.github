# PERLA

### Partecipazione E Rilevazione Locale Ambientale

**Progetto scolastico di studio e progettazione di una rete meteorologica e ambientale a Soverato, Calabria.**

PERLA nasce con l'obiettivo di approfondire la rilevazione dei dati meteorologici e ambientali attraverso un percorso di progettazione, sviluppo software, studio dell'elettronica e collaborazione tra studenti.

Il progetto è attualmente **in fase di studio e progettazione**. La rete di monitoraggio non è ancora installata né collaudata.

---

## Il nostro obiettivo

Progettare una soluzione che permetta, in futuro, di:

- Raccogliere dati meteorologici e ambientali attraverso sensori dedicati.
- Conservare localmente i dati anche durante le interruzioni della connessione Internet.
- Trasmettere le misurazioni a un'infrastruttura server.
- Consultare dati e serie storiche attraverso un'interfaccia web.
- Studiare un sistema di alimentazione autonomo e sostenibile.
- Documentare e verificare le scelte tecniche adottate.

## Le nostre aree di lavoro

| Area | Attività |
|---|---|
| Meteorologia e sensori | Studio dei dispositivi di rilevazione e delle condizioni di installazione |
| Hardware ed energia | Elettronica, alimentazione fotovoltaica e batterie |
| Acquisizione dati | Software locale e gestione delle misurazioni |
| Backend e database | Servizi applicativi, archiviazione e sincronizzazione |
| Frontend | Interfaccia web e visualizzazione dei dati |
| Infrastruttura e sicurezza | Rete, server e protezione dei sistemi |
| Test e documentazione | Verifiche tecniche e tracciabilità dei risultati |

## Come lavoriamo

PERLA utilizza GitHub per organizzare le attività, documentare le decisioni e coordinare lo sviluppo.

Il flusso di collaborazione prevede branch individuali, integrazione nel branch `dev` e successiva promozione delle versioni verificate nel branch `main`.

Le scelte progettuali restano soggette a revisione e verifica.
